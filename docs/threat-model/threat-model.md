# Модель угроз

## Активы

1. Денежные средства клиентов.
2. Распоряжения на перевод.
3. Персональные данные.
4. Криптографические ключи и подписи.
5. Журналы аудита.

## Основные угрозы

| Угроза | Контроль |
| --- | --- |
| Подмена суммы или получателя | Подпись конкретных параметров операции |
| Повтор запроса | `Idempotency-Key`, nonce и timestamp |
| Двойное списание | Ledger, транзакции БД, optimistic locking |
| Перевод без согласия клиента | Антифрод, step-up authentication, блокировка подозрительных операций |
| Утечка персональных данных | Маскирование, ограничение логирования, шифрование |
| Компрометация ключей | HSM/KMS, ротация, разделение ролей |
| Ошибка внешнего платежного шлюза | Outbox, retry policy, сверка статусов |

## Остаточные риски

В учебной версии криптография, AML, антифрод и БД представлены заготовками. Для промышленной реализации нужны сертифицированные СКЗИ, полноценная модель ролей, журналирование в неизменяемом хранилище и интеграционные проверки.
