# Матрица соответствия требованиям

| Требование | Реализация в проекте |
| --- | --- |
| 161-ФЗ: распоряжение клиента на перевод | `TransferOrder`, подтверждение через `/confirm` |
| 161-ФЗ: уведомление клиента | Запланировано через `BankTransfers.Workers` и outbox |
| 115-ФЗ: AML/KYC | Интерфейс `IAmlService`, заготовка `AllowAllAmlService` |
| 152-ФЗ: персональные данные | Маскирование и запрет логирования чувствительных данных должны быть добавлены в Infrastructure |
| 63-ФЗ: электронная подпись | Интерфейс `ICryptoService`, подтверждение параметров перевода |
| ГОСТ Р 57580.1-2017 | Предусмотрены аудит, разделение слоев, контроль доступа, журналы |
| Положение 821-П | Предусмотрены антифрод, аудит, криптографическое подтверждение |
| Положение 716-П | Отдельные проверки риска, статусы отказов и трассировка операций |
