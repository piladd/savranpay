# Криптографическая модель

Подтверждение перевода должно выполняться для конкретного набора параметров:

```json
{
  "operationId": "uuid",
  "payerAccount": "40817810...",
  "recipientAccount": "40817810...",
  "recipientBankBic": "044525225",
  "amount": 150000,
  "currency": "RUB",
  "purpose": "Перевод собственных средств",
  "createdAt": "2026-05-14T12:00:00+03:00",
  "nonce": "random-value"
}
```

В промышленном контуре вместо `DemoCryptoService` должен использоваться криптопровайдер с поддержкой ГОСТ-алгоритмов и безопасным хранением ключей в HSM/KMS.
